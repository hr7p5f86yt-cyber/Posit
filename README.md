# Posit

絵を描くための 3D デッサン人形。ブラウザだけで動き、ホーム画面に追加するとアプリのように開きます。

## 置き方（GitHub Pages）

1. この**フォルダの中身**をリポジトリの**直下**に置く
   （`index.html` がリポジトリのトップに来るようにする。フォルダごと入れない）
2. Settings → Pages → Source を `Deploy from a branch` → `main` / `(root)` → Save
3. 1〜2 分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` が開く
4. **Safari** で開き、共有 → 「ホーム画面に追加」

リポジトリは Public にしてください。Private のままだと Pages は有料プランが必要です。

## 更新のしかた

変更したファイルを push するだけです。ページを開き直すと新しい版に自動で入れ替わります
（Service Worker が新しくなると、一度だけ自動で読み直します）。

v50 から、新しい版を取り込むときはブラウザの HTTP キャッシュ（GitHub Pages は 10 分ほど残す）を通さずに取ります。
v49 では、新しい app.js と古い viewer.js が混ざって「setBodyMode is not a function」と出ることがありました。
起動したときに app.js と viewer.js の版が違えば、1 度だけ自動でキャッシュを消して読み直します（それでも違うときは、
viewer.js を上げ忘れていないか確かめるよう知らせます）。

うまく切り替わらないときは、パネルの「**困ったとき**」→「**キャッシュを消して再読込**」。
同じ場所に今動いているバージョンが出ます。

## 画面

下のタブで切り替えます。

- **ポーズ** — 上の5つのボタンで切り替わります
  - **全身**: 9カテゴリ76ポーズ。1画面に 9〜18 個（3〜4列の小さな格子）。カテゴリも各ページも**左右にスライド**。
    虫めがねで**名前から探せます**（ひらがな・カタカナは区別しません）
  - **手**: グー・パー・OK など16種を、両手／人形の左手／人形の右手に当てる
  - **顔**: 見上げる・振り向く・口を開けるなど14種
  - **履歴**: 直近30件から呼び戻す
  - **保存**: いまのポーズに名前を付けて残す（関節の角度と手の形）。**画面を画像に**で PNG を書き出す。
    **背景を透過して画像に**で、背景と床の線を抜いた PNG も書き出せます
- **関節** — 選んだ関節を3軸で動かします。関節は体幹／左腕／右腕／左脚／右脚の
  まとまりに分かれていて、**左右にスライド**して切り替えます。
  **手・足は選ばなくても、押して動かすと腕・脚ごとついてきます**。ほかの関節はタップして選び、**そのまま押して動かすと直接曲がります**。
  関節のまわりの**回転の輪（赤・緑・青）**をなぞると、その軸だけで回ります（下の「関節を直接動かす」）
- **設定** — 見え方／体とモデル／ライト／カメラ の4枚
- **クロッキー** — 時間・枚数・カテゴリを決めて全画面で回します

上部のボタンは、左から「パネルの開閉」「**困ったとき**（`?`）」…（右へ）「1つ戻す」「**やり直す**」「**画像に保存**」「左右反転」「全身リセット」。
どれも指で押しやすい 44pt の大きさです。

- **画像に保存**（v46） … 押すと「画面を画像に」「背景を透過して画像に」の小窓が開きます（パネルの「保存」と同じ）
- **全身リセット** … はじめのポーズ（**両手を広げる**）に戻します。手の形も戻します

### はじめのポーズ（v46）

起動したとき・全身リセット・「すべての設定を初期値に戻す」のポーズは、**両手を広げる**（ポーズ一覧の「立ち」にあるものと同じ）です。
関節の「戻す」「この関節を戻す」も、その関節をこのポーズの角度に戻します。
変えるときは `viewer.js` の先頭の `DEFAULT_POSE_ID` に、`poses.js` のポーズの `id` を書きます。

### パネルを使わずに動かす（v46）

下のパネル（ポーズの一覧・関節のスライダ・設定・クロッキー）はそのまま残し、**人形の上だけでポーズを作れる**ようにしています。
パネルは**開くたびにたたんだ状態から始まります**（v47）。下のタブを押すか、上の ⌃ で開きます。
人形の関節を選んでも、たたんだパネルは開きません（開いたときは関節のページになっています）。

| したいこと | 人形の上での操作 |
|---|---|
| 関節を選ぶ | 人形をタップ。印を出しているときは**印**をタップ（丸 = 腕・脚、四角 = 体幹、二重の丸 = 手・足） |
| 曲げる | 選んだ所を押したまま動かす。印は選んでいなくても押したまま動かせば曲がる |
| 腕・脚ごと動かす | 手・足（二重の丸）か、手・足そのものを押して動かす |
| 決まった向きに回す | 選んだ関節のまわりの輪（赤・緑・青）をなぞる |
| 戻す・反対側へ写す | 左上の帯の「戻す」「反対へ写す」 |
| 手の形・顔の向きと表情 | 手を選ぶと左上の帯に「手の形」、首・頭を選ぶと「顔」。押すと一覧の小窓が開きます |
| 見る向き | 下の帯（正面・左横・右横・後ろ・上・全体）、何もない所を 2 回タップで全体 |
| 1 つ戻す・やり直す・画像に保存 | 上のバー |
| ポーズを選ぶ | 画面下の「**ポーズ**」（カテゴリ・ランダムつき。パネルの一覧と同じ）（v48） |
| 腰を動かす（しゃがむ・重心を移す） | 腰（骨盤）を押して動かす（v49） |
| 体全体を動かす・回す | 画面下の「**体全体**」→ 人形を押して動かす・緑の輪（v49） |
| 手・足を固定する | 右下の「固定」の右手・左手・右足・左足（v49） |
| 2 つのポーズを行き来する | 画面下の「**キープ**」（v48。下を見てください） |

「**キープ**」（v48）は、ポーズを 1 つ取っておく所です。

1. 取っておきたいポーズで「キープ」を押す（ボタンが橙色の「⇄ キープ」になります）
2. ほかのポーズに変える（一覧から選ぶ・動かす）
3. 「⇄ キープ」を押すと、キープしたポーズと**入れ替わります**（いまのポーズはキープの方へ移る）。もう一度押すと戻ります

「1 つ戻す」と違って、間にいくつ操作をしても行き来できます。体の位置・手の形も入ります。端末に覚えておくので、開き直しても残ります。
× でキープを消せます。

関節の印について（**はじめは出しません**。v47。関節タブの「関節の印を出す」で出せ、選び方は端末に覚えておきます）:

- 選んでいる関節は橙色、体の向こう側にある関節は薄く出ます
- 引いて小さく見ているときは、印が重なる所（胸のまわりなど）でよく使う方を残します（手・足・肘・膝が先）。拡大すると全部出ます
- 印は輪より近くを押したときに優先します（輪の上に別の関節の印があるとき）
- 画像には写りません。クロッキー中は出ません
- 光の玉は、両手を広げたときの手にかからないよう、少し小さくしました（104 → 84px）

「ランダム」と「写真から」は、ポーズのカテゴリ列の右端に**小さなアイコン**として置いてあります
（サイコロ＝ランダム、カメラ＝写真から）。左端の虫めがねは名前で探す欄を開きます。

### 画面の上ですぐ使うボタン（v44）

パネルを開かなくても使えるように、人形のそばに 2 つの帯を出します。

- **下の帯（見る向き）** … 正面／左横／右横／後ろ／上／全体。左右は人形から見た左右。
  「全体」はいまの向きのまま、人形全体を画面に収めます。帯のぶんは人形がかからないように空けてあります
- **左上の帯（選んだ関節）** … 関節を選ぶと出ます。名前／**戻す**（その関節だけ、はじめのポーズの角度へ）／**反対へ写す**（選んだ関節のある腕・脚を、
  反対側へ鏡に映して写す。腕なら手の形も）／**手の形**（手のとき）・**顔**（首・頭・あごのとき）／×（選択を外す）。
  上のバーの選択中の名前は、この帯に移しました

### 操作のしかた・指の動き（v44）

はじめて開いたときに「操作のしかた」を 1 度だけ出します。「？」（困ったとき）→「操作のしかた」でいつでも開けます。

| 指の動き | すること |
|---|---|
| 手・足を押して動かす | 腕・脚ごとついてくる（引っ張る） |
| 関節をタップ | 選ぶ（何もない所をタップすると外れる） |
| 選んだ所を押して動かす | その関節が指の方へ曲がる |
| 輪をなぞる | その軸だけで回る |
| 何もない所を 1 本指で | カメラを回す |
| 2 本指でつまむ・動かす | 拡大・縮小、平行移動 |
| 何もない所を 2 回タップ | いまの向きのまま全体を画面に収める |

## 左右について

画面に出る「左」「右」は、すべて**人形から見た左右**です（人形の左手＝正面から見て画面の右側の手）。
関節の名前（左上腕など）、手の形の「人形の左手」、見る範囲の「人形の左」、骨・筋肉の名前の（左）、
カメラの向きの「左横」（人形の左側から見る）が、どれも同じ決まりです。

## パネルの高さ（3段）と人形の見える場所

パネルは **たたむ／半分／広く** の3段です。つまみを上下に動かして離すと近い段に吸い付き、
速く払うとその向きへ1段動きます。動かさずにつまみをタップすると、たたむ／開くです。

パネルや上のボタンに隠れない**空いている所に人形が収まる**ように、カメラが見る窓を合わせます
（three.js の `setViewOffset`）。パネルを広くしても人形の頭や足がパネルの下に隠れません。
横長の画面（iPad の横向き）ではパネルが右にあるので、左の空いている所に収めます。

## 関節を直接動かす

### 手・足を引っ張る（v44）

**手（手首から先）か足（足首から先）を押したまま動かすと、そこが指の下へ来るように腕・脚がついてきます。**
選んでいなくても使えます（動かさずに離せば、ふつうのタップで選ばれます）。

- 腕は上腕と前腕、脚は腿と脛が動きます。手・足の**世界での向きはつかんだときのまま**です（足の裏が床を向いたまま、など）
- 肘・膝は**蝶番（ちょうつがい）のまま**曲がります。どちら側に出すかは（v48）、今の向きのまわり 16 方向と
  「自然な向き」（肘は下・後ろ・少し外、膝は前・少し外。体の向きに合わせて回す）を比べ、
  **可動域を越える量（無理な形）**・今の向きからの変わり方・自然な向きからのずれで点を付けて、いちばん良いものにします。
  下ろした手を真上へ引いたときに肘が後ろへ引けきる、膝が後ろへ曲がる、といった形を避けます。
  手を横へ持ち上げると、腕全体が振り子のように振れます（肘が急にねじれません）
- 動くのは画面の面の中です。前後（奥行き）へ動かしたいときは、横からの向きにしてから引っ張ります
- 可動域の制限が入っているときは、その範囲の中でいちばん近づく形になります。届かない所へは伸びきったところで止まります
- 解き方: 肩（股）から目標までの距離と骨の長さから肘（膝）の位置を一度に出し（余弦定理）、
  上腕は骨の向きと肘の軸の 2 本を合わせるように回します。可動域で止まったときだけ、角度を少しずつ動かして近づけます（`limbPull.js`）
- いらないときは、関節タブの「手・足を引っ張って腕・脚ごと動かす」で切れます

### 腰を引っ張る（v49）

**腰（骨盤）を押したまま動かすと、手・足を引っ張るのと同じように腰が指の方へ動きます。** 選んでいなくても使えます。

- **固定した足はその場に残り、固定していない足は体と一緒に動きます**（v51。v49・v50 は両足を自動で留めていました）。
  両足を固定して下へ引けばしゃがむ、横へ引けば重心が移る。片足だけ固定すれば、もう片方の足を浮かせたまま腰を動かせます
- 足をどちらも固定していないときは、体全体が動きます（床に立ったまま）
- 片足だけ固定して腰を下げたとき、固定していない足は**床より下へは行かず**、床に着いたところで止まります（膝が曲がる）
- 画面の面の中で動きます（前後に動かすときは、横からの向きにしてから）
- 足が届かない所までは行きません（脚が伸びきったところで止まります）

### 体全体を動かす・回す（v48・v49）

- 画面下の「**体全体**」を押すと**体全体モード**になります（ボタンが橙色。もう一度押すと終わります）
- 体全体モードの間は、**人形のどこを押して動かしても、体全体が床の上を滑ります**（固定した手・足も一緒に動きます）
- **緑の輪** … 体全体の向きを変えます。赤・青の輪で前後・左右に傾けます（体全体モードでは、輪は線の真上を押したときだけ）
- 体の位置はポーズの一部として、戻す・保存・履歴・キープにも入ります（`bodyPos`、cm）

### 手・足の固定（ロック）（v48・v49）

画面の右下の「**固定**」の **右手・左手・右足・左足** のボタン（v49。左右は人形から見た左右）を押すと、
その手・足は**世界の同じ位置・向きに残ります**。ボタンが橙色になり、人形の手・足に錠前の印が出ます。もう一度押すと外れます。
手か足を選んで、左上の帯の「固定」を押しても同じです。

- ほかの所を動かしても（腰を動かす・体をひねる・肩を回す・スライダ）、固定した手・足はその場に残り、腕・脚が付いてきます
- 足を固定している間は、床合わせで体を上下させません（片足を固定して腰を上げれば、体ごと浮かせることもできます）
- 固定した手・足そのものを引っ張ると、固定する位置も一緒に動きます
- 届かない所までは伸びません（腕・脚が伸びきったところで止まります）
- ポーズの一覧から選ぶ・全身リセット・左右反転で固定は外れます。1 つ戻す・やり直すのあとは、その姿勢の位置で固定し直します

### 関節を選んで曲げる

1. 人形の関節をタップして選ぶ（下の関節タブに名前と角度が出ます）
2. 選んだ部分（例：前腕なら肘から手首まで）を**押したまま動かす**と、その関節が指の方へ曲がります

画面の面の中で曲がるので、奥行きの向きに曲げたいときはカメラを回してから動かします。
可動域の制限が入っているときは、その範囲の中で動きます。動かす前の姿勢は「1つ戻す」で戻せます。
選んでいない所を押したときは、これまで通りカメラが回ります。

### 回転の輪（3軸）

関節を選ぶと、そのまわりに**赤・緑・青の 3 つの輪**が出ます。輪をなぞると、その軸だけで回ります。

| 輪 | 軸 | 動き（上腕の例） | スライダ |
|---|---|---|---|
| 赤 | X | 前後に振る | 1 本目（前後） |
| 緑 | Y | ひねる（骨のまわり） | 2 本目（ひねり） |
| 青 | Z | 左右に開く・閉じる | 3 本目（左右） |

- 輪 1 つがスライダ 1 本と同じ動きです。スライダの名前の前にも同じ色の点が付いています
- 輪は関節が回るのに合わせて向きが変わります（緑はいつも骨のまわり）。
  中の作り: 角度は X → Z → Y の順に重ねているので、赤は親の向き、青は X を回したあとの向き、緑は X と Z を回したあとの向きに置いています
- 奥側の半分は暗く・薄く描くので、手前と奥が分かります
- 回している間は、画面の上に「左上腕・前後 35°」のように軸の名前と角度が出ます。可動域の制限が入っていれば、その範囲で止まります
- 正面を向いた輪はぐるっと回すように、横を向いて細く見える輪は線に沿って押すように動かします
- 輪をタップしただけでは選択は外れません。輪の上を押すと、関節の部分を押すより輪が先になります
- 輪は画面の上でいつも同じ大きさです（拡大・縮小しても変わりません）
- いらないときは、関節タブの「回転の輪（3軸）を出す」で消せます。画像の書き出しとクロッキー中は出ません

## モデルの読み込み方

**Sketchfab** からダウンロードした **zip をそのまま選べます**。展開の必要はありません。

1. Sketchfab でモデルのページを開き、Download 3D Model（無料登録が必要）
2. 形式は **glTF** を選ぶ（USDZ ではなく）
3. ダウンロードした zip を、設定 → モデル → 読込 で選ぶ

`.gltf` 単体では読み込めません。中身が `scene.bin` という別ファイルに入っているためです。
すでに展開してしまった場合は、**scene.gltf と scene.bin をまとめて選択**してください。

GLB の1ファイル、Mixamo から書き出した FBX は、そのまま1つ選ぶだけです。

## 見る範囲と体型

設定タブで切り替えます。

- **見る範囲** — 全身 / 上半身 / 顔 / **手だけ** / **足だけ**。左右はチップで切り替えます
  - 手だけ・足だけは、**片側の手（足）と、前腕（すね）の手首（足首）寄り**だけを描きます。
    手首から前腕の 4 割、足首からすねの 3.5 割まで残るので、腕・脚とのつながりも分かります
  - どの面を残すかは**スキンの重み（その面がどの骨に引っ張られるか）**で決めます。
    以前は空間を平面 1 枚で切っていたため、気をつけのように手が腿の横にあると腿まで映っていました
  - カメラは手の甲の斜め（親指側）、足は外くるぶし側の斜め前から自動で向けます
  - **カメラは手（足）に固定**されます。全身のポーズを変えて手が動いても、
    画面の中の手の位置・大きさ・傾きは変わりません。指で回した向きもそのまま保ちます
  - 面の線を出していても、線は手（足）のぶんだけになります
- **体型** — 中性 / 男性 / 女性。骨の配置と、表面の変形（モーフ）の両方で体つきを変えます。
  詳しくは下の「体型の違い」を見てください
- **面の線を出す** — 面の割れ方が見えるので、陰影を取るときの参考になります
- **面の線の数**（v45） — 少なめ／ふつう／多め／とても多め。線を出していなくても、選ぶと線が出ます。端末に覚えておきます
  - 面の割れに沿うとき: **少なめ** = 四角の面（2 つの三角形が四角を作っている所は対角線を描かない。素体の網目は約 9 割が四角）、
    **ふつう** = 三角形の縁（前の版まで）、**多め・とても多め** = 三角形を 2 分割・3 分割した線も描く
  - 乳房の線も同じ段に合わせます（少なめは斜めの線なし、多め・とても多めは間隔 1/2・1/3）
- **面の線の引き方** — **面の割れに沿う**（網目のとおり）／**体に沿った輪切り**（v48。v45 の「等間隔の輪切り」を作り直し）
  - 胴・首と頭・左右の腕・左右の脚・左右の足のそれぞれを、**その部分の軸に直角な輪**と、**軸に沿った縦の線**で切ります。
    腕を曲げても、輪は腕を巻くように付いてきます（立体の回り込み・断面の向きを取るのに向きます）。
    v45 は世界の左右・上下・前後の平面で切っていたので、斜めになった腕や脚で線が詰まったり斜めに走ったりしていました
  - 輪の間隔は体の高さの 1/16（少なめ・約 11cm）、1/26（ふつう・約 7cm）、1/42（多め・約 4cm）、1/64（とても多め・約 3cm）。
    縦の線はひと回りで 6・8・12・16 本
  - 三角形ごとに、いちばん重みの大きい骨からどの部分かを決め、3 頂点とも同じ部分の軸で測ります（部分の境目では線が切り替わります）。
    指は手の、つま先は足の部分に入ります。線は体の形の座標（スキン前）で引くので、ポーズを変えても体に付いたまま動きます
- **線の太さ・線の濃さ**（v44） — 面の線の太さ（×0.5〜×6。×1 が前の版までと同じ 1 画素の細さ）と濃さ（10〜100%）。
  つまみを触ると面の線が出ます。端末に覚えておきます。
  WebGL の線は 1 画素より太くできないので、線は三角形そのものを塗り、**三角形の縁に近い所だけ**を線の色にしています
  （縁からの距離を画面の画素で測るので、拡大・縮小しても線は同じ太さ）。乳房の網目は細かいので、
  「何本目の輪・何本目の向きか」が整数になる所を塗る方眼のやり方で描きます（太くしても途切れません）


## 体型の違い

読み込んだモデルから、起動時に**男性・女性の 2 つの変形（モーフ）**を作ります。
中性は元のモデルのままです。ポーズを付けても変形はついてきます。
違いが見て分かるよう、平均的な男女差を少し強め（およそ 1.5 倍）にしていますが、
成人の個人差の範囲には収まる量です。量は `bodyShape.js` の先頭の `SHAPE` で変えられます。

| 部位 | 男性 | 女性 |
|---|---|---|
| 肩幅（鎖骨の長さ） | 広い（+15%）。三角筋・僧帽筋が張り、首の付け根から肩へ盛り上がる | 狭い（−12%）。なで肩寄り |
| 胸 | 大胸筋が前に出る | 乳房（下の「乳房の形」を参照） |
| 背中 | 広背筋が張り、逆三角形になる | 平らめ |
| ウエスト | くびれが少なく寸胴 | 細くくびれる（横幅 −15%、前後も薄く） |
| 骨盤・腰幅 | 狭い。脚の付け根が内側に寄る | 広い。脚の付け根が外に開く |
| お尻 | 小さく締まる | 丸く後ろへ張り出す |
| 下腹部 | 平ら | へその下が少し丸い |
| 腕・首 | 太い（上腕 +21%、首 +22%） | 細い |
| 太もも | 膝寄りが太い | 付け根寄りが太い |
| すね | 太い | 細い |
| 手首 | 太い | 細い |

### 全体のシルエット（成人の寸法との比べ）

素体の表面の頂点から、身長に対する横幅・前後の厚みを測り、成人の計測値（ANSUR）と比べて直しています。

| 部位（身長比） | 成人の目安 男／女 | 前の版 中性・男／女 | いま 中性・男／女 |
|---|---|---|---|
| ウエストの横幅 | 0.18 ／ 0.17 | 0.11・0.12 ／ 0.10 | 0.16・0.16 ／ 0.15 |
| 腰（大転子）の横幅 | 0.20 ／ 0.225 | 0.225・0.21 ／ 0.257 | 0.225・0.21 ／ 0.245 |
| 肩幅（三角筋まで） | 0.28 ／ 0.26 | 0.22・0.24 ／ 0.21 | 同じ・女性は鎖骨を少し広げた |

- **ウエスト** … サンプル素体は胸の殻とお腹の玉のあいだが関節で、成人よりずっと細く、コルセットを締めたように見えていました。
  どの体型にもかかる「土台の補正」として、いちばん細い高さを中心に、横へ最大 48%・前後へ 18% なだらかに広げます（`bodyShape.js` の `BASE`）。
  人形らしい関節の区切りは残ります
- **女性の腰〜腿** … 腿の付け根の外側が大きく張り出して、乗馬ズボンのような形になっていたので、腰の横幅・脚の付け根のずらし・腿の付け根の太さを弱めました。
  画家向けの目安（女性の腰幅は肩幅と同じくらいか少し広い）に合わせています
- **女性の肩と首** … 鎖骨の長さを 0.88 → 0.93 倍、首の細さを弱めました（細すぎて頭が浮いて見えたため）

### 乳房の形（別の部品）

乳房は、胸の殻を変形させるのではなく、**胸にのせる別の部品**として作ります（`breastParts.js`）。
サンプル素体はもともと胸の殻・お腹の玉・関節の玉といった部品の組み合わせなので、その作りに合わせています。

前の版まで胸の殻そのものを押し出していましたが、殻は頂点がまばら（間隔 2.5cm）で、
ふちが V 字に巻き込み、横が平らな壁になっているので、どう押し出しても
「尖る」「横が壁になる」「下がとがる」といった無理が出ていました。

部品の作り方:

1. 女性の体つきにした胸の殻の表面を、前から測る（前を向いた面だけ。ふちの裏や横の面は使わない）
2. 測った面をならして土台にする（殻の三角形の折れ目を写さない）
3. 土台から、胸の丸みに沿った向きへ乳房の厚みだけ持ち上げる（細かい網目: 1 つにつき 32 輪 × 72 方向）
4. 縁は殻の面より 1cm ほど沈めて継ぎ目を隠す。殻のふちを越える所は内へ巻き込んで、ふちの裏へ隠す
5. スキンの重みは、真下にある殻の三角形の重みを写す。ポーズ・頭身を変えても殻と一緒に動き、曲がる

形（解剖学に合わせる）:

- **土台** … 上は第2肋骨、下は第6肋骨（乳房下溝）、内側は胸骨のふち（正中から 1cm 足らず）、外側は前腋窩線の手前。上外側は脇の下へ少し傾く
- **左右のあいだ** … 土台どうしは胸骨の幅ぶんしか離れていません。内側の縁は胸骨のふちから急に立ち上がるので、
  正面から見たすき間は 1.5〜2cm ほどです（前の版は内側をなだらかにしすぎて、5cm ほど空いて見えていました）
- **乳頭** … 第4肋間、正中から胸の半幅の約 0.41 倍（v42 で 0.5 → 0.41。左右が離れて見えたため寄せました）。土台の中心より少し下。
  土台は乳頭より外側（脇の下の方）へ広く、内側へ狭くして、内側の縁は胸骨のふちのまま、外側の縁も前の版と同じ所に保っています
- **横から** … 上極は鎖骨の下からほぼまっすぐな斜面、下極は丸く張り、乳頭で角を作らずにつながる
- **上から** … 左右それぞれ丸い弧。胸のかごが丸いので外へ 12° ほど向く（v42 で 15° → 12°）

部品は女性のときだけ表示し、質感・透明・影・面の線は胸の殻と同じになります。
面の線は、細かい網目を全部描くと黒く潰れて見えるので、**体の網目と同じくらいの間隔（約 1.5cm）**の輪・放射・斜めの線だけを、
乳房の丸みに沿って描きます。
手だけ・足だけ、骨格だけ・筋肉だけの表示では出ません。
大きさや位置は `breastParts.js` の先頭の `BREAST` で変えられます。

### 手の男女差

| 部位 | 男性 | 女性 |
|---|---|---|
| 手の大きさ | やや大きい（+4%） | やや小さい（−5%） |
| 掌 | 幅広く（+9%）厚い（+13%） | 細く（−7%）薄い（−8%） |
| 指 | 太く、節が目立つ（+15%） | 細く、先の節ほど細る |
| 拳の山・指の関節 | 中手骨頭と第2関節が手の甲の側へ 3.4mm 張り出して骨ばる | 1.2mm 低く、なだらか |
| 人差し指と薬指 | 薬指のほうが長い（2D:4D 比が小さい） | 人差し指と薬指がほぼ同じ |

手の大きさと指の長さは骨の倍率で、掌と指の太さは表面の変形で付けています。
手だけを映すときは、手の大きさに合わせてカメラの距離も変えます。

- 乳房は「胴の中心より前にあるか」という位置で効かせ、面の向きでは決めません
  （面の向きで決めると、脇の下側だけ押し出されずにえぐれて見えるため）。
  素体の胸は殻のような形で下と脇のふちが内へ巻き込んでいるので、ふくらみはふちの手前で丸く消し、
  ふちと脇の近くは面のつながりに沿ってならして、段差やしわが出ないようにしています
- 腰幅は「脚を横に引き伸ばす」のではなく**脚全体を横にずらす**ので、腿の付け根に羽のような出っ張りは出ません
- 骨格表示も体型に合わせて組み直します（切り替えたあと一瞬「骨格を組み立てています…」と出ます）。
  骨盤は女性のほうが横に広く、男性のほうが幅が狭くなります
- 変形はモデルの骨（肩・腕・脚・首）の位置から自動で位置合わせするので、Xbot 以外のモデルにも効きます。
  元から男女のはっきりしたモデルでは、変化が強く出すぎることがあります。そのときは「中性」を選んでください


## 手の形

ポーズタブの「手」で、平ら・自然・パー・グー・指差し・ピース・OK・いいね・握る・つまむ・
爪を立てる・手刀・3・4・ロック・電話 の 16 種を、両手／左手／右手に当てます。

指を曲げる軸は、**指ごとに骨の位置から**決めています（固定の軸で回すと、
手のひらの向きや指の付き方がリグごとに違うので崩れます）。

- 人差し指〜小指 … 曲げる＝手のひらの側へ、開く＝親指の側へ
- 親指の付け根（CM関節）… 解剖学の定義どおり、曲げる＝**手のひらの面の中で小指側へ**、
  開く＝**手のひらから前へ離す**
- 親指の先の二節 … 人差し指と中指の第二関節のほうへ曲がる（握ったときに指の上へ乗る）

軸はどれも「動かしたい向き」との外積で作るので、**右手は自動で左手の鏡像**になります
（全ポーズ×全種で左右の差 0mm）。
親指の角度は、実際の素体で「グーで人差し指と中指の中節に乗る」「OK で人差し指の先に触れる」
などの位置になるよう数値で探して決めました。

基準姿勢の手の向きは「指は真下・**指の付け根の並び（小指→人差し指）が前後**」
＝手のひらが腿を向く向きです。以前は親指を前に向けていたため、手のひらが 30° ほどねじれていました。

## 頭身

設定 → 頭身 のスライダで **2〜9 頭身**に変えられます。
背丈そのものは変わらないので、画面上の大きさは保たれます。
頭身はもともと解剖学の決まりではなく絵の約束ごとなので、実際の人の計測値
（おとな約 7.5 頭身・6 歳ごろ約 6 頭身・1 歳ごろ約 4 頭身）と、漫画やイラストのデフォルメ（3 頭身・2 頭身）を
つないだ比率の表（`proportions.js`）から、部位ごとの長さと太さを決めています。

| 頭身 | 股の高さ（背丈比） | 首の付け根〜股 | 首 | 肩幅（背丈比） | 手足の太さ | 腕（肩〜手首） |
|---|---|---|---|---|---|---|
| 9 | 0.53 | 0.32 | 0.04 | 0.235 | 細め | 0.34 |
| 7.5 | 0.49 | 0.33 | 0.04 | 0.230 | 基準 | 0.33 |
| 6 | 0.44 | 0.35 | 0.05 | 0.231 | 基準 | 0.33 |
| 5 | 0.40 | 0.35 | 0.05 | 0.237 | +4% | 0.33 |
| 4 | 0.36 | 0.35 | 0.04 | 0.250 | +10% | 0.31 |
| 3 | 0.32 | 0.32 | 0.03 | 0.270 | +18% | 0.27 |
| 2 | 0.23 | 0.26 | 0.02 | 0.300 | +30% | 0.21 |

この表から分かること:

- **胸（胴）の大きさは、頭身を下げてもあまり変わらないのが正しい**。
  背丈に対する胴（首の付け根〜股）の長さは、9 頭身でも 3 頭身でもほぼ 3 割強。2 頭身でやっと縮み始めます
- 頭が大きくなったぶんを引き受けるのは**脚**。股の高さは 7.5 頭身の 0.49 から、3 頭身で 0.32、2 頭身で 0.23 まで下がります
- **首**は短くなり、4 頭身より下では頭が胴にほぼのります
- 肩幅・胴の厚み・手足の太さは、背丈に対して**むしろ少し増えます**（ずんぐりした体になる）
- 腕は、垂らした手首が股〜腰の横あたりに来る長さ。デフォルメが強いほど短くなります

モデル本来の頭身の近くでは、モデルの個性（脚の長さなど）を残し、頭身を大きく変えるほど表の比率に寄せます。

## クロッキーの見え方

「画角」を **いろいろな画角** にすると（既定）、1 枚ごとに
向き（正面・斜め・横・後ろ）、高さ（あおり・目の高さ・見下ろし・俯瞰）、レンズ（24〜85mm）を変えて出題します。
前の 1 枚と近い向きは避けます。今の画角は画面上部に「左斜め後ろ・見下ろし・35mm」のように出ます。
終わるとカメラとレンズは出題前に戻ります。

- **ポーズごとに左右をランダムに反転** … 半分の確率でポーズを左右反転して出します（名前に「（反転）」）
- **終わる前に音と振動で知らせる**（既定オン）… 残り 3・2・1 秒で短い音。最後は高い音。
  振動に対応した端末では震えます（iPhone の Safari は振動に対応していないので音だけです）

クロッキータブで、**出題中だけ**の見え方を決められます。

- 表示するモデル（素体 / 筋肉 / 骨格 / 重ねて）
- 見る範囲（全身 / 上半身 / 顔 / 手だけ / 足だけ）
  - 手だけ・足だけのときは **左右ランダム / 左だけ / 右だけ** を選べます
  - 手だけのときは **手の形も毎回変える**（16 種からランダム、前回と同じ形は避ける）。
    画面上部の名前は手の形の名前になります
- 体型（いまのまま / 中性 / 男性 / 女性 / **毎回ランダム**）。ランダムのときは前回と違う体型にします
- 面の線

画面上部には「右手・女性・50mm」のように、左右・体型・画角が出ます。
終わると見え方・体型・手の形は出題前に戻ります。手だけを 30 秒で回す、といった練習ができます。
骨格を重ねて「毎回ランダム」にすると、1 枚ごとに骨格を組み直すので切り替えに少し時間がかかります。

## すべての設定を初期値に戻す

v44・v45 で増えた設定（面の線の数・引き方・太さ・濃さ、透過の書き出しの設定、手・足を引っ張る）も初期値に戻します。

設定 →「体とモデル」のいちばん下か、左上の「？」（困ったとき）にあるボタンで、
見え方・体つき（体型・頭身）・ライトと影・カメラと床・見る範囲・クロッキーの設定・パネルの高さを、
はじめて開いたときの状態に戻します。確認が出てから戻します。
v42 から**ポーズと手の形も初期の立ち姿に戻します**（写真から当てたポーズも含みます。写真の重ね表示も消します）。
戻す前のポーズは「1つ戻す」で取り戻せます。**履歴・保存したポーズ・読み込んだモデルはそのまま**です。
座ったポーズのまま戻しても床に沈まないように、「基準姿勢に合わせる」を測り直すときは、
接地のために上下にずらしている分をいったん外してから足の高さを測ります（すでにオンなら何もしません）。

## ライトと光の玉

画面右上の**光の玉**で、光がどちらから当たっているかが分かります。

- 玉の陰影 … いまのライトで球を照らしたときの見え方。明暗の境目の向きがそのまま分かります
- 黄色い点と矢印 … 光の来る方向と、光の進む向き
- 内側の円 … 手前（見ている側）から当たる光。中心が順光、円のふちが真横
- 外側の輪 … 奥から当たる光（逆光）。点は輪郭だけの表示になります
- **なぞる** … 光の向きが変わります。なぞっている間は、人形のそばに黄色い光の矢印が出ます。
  向きは「いま見ている画面」が基準なので、回り込んで見ていても右へなぞれば画面の右から光が当たります
- **タップ** … 強さとライトの組み合わせの小窓が開きます。外を触ると閉じます

ライトの組み合わせ（設定 → ライトと影 にもあります）:
標準 / 強い明暗 / やわらか / 真横から / 真上から / 逆光 / 下から / まぶしく

強さは 0〜20 まで上げられます（前は 6 まで）。つまみは弱いところを細かく、強いところを大きく動くようにしてあります。
補助光と環境光を 0 に近づけるほど、影の側が暗く落ちて明暗がはっきりします。
光の玉が邪魔なときは、設定 → ライトと影 の「光の玉を画面に出す」で消せます。クロッキー中は出ません。

## 写真からポーズを読み取る

ポーズタブのカメラのアイコンを押すと、読み取りの窓が開きます。

- **写真を選ぶ** … 写真アプリの写真から選ぶ
- **画像を貼り付け** … Pinterest などで画像を長押しして「コピー」したものを、そのまま読み取る。
  iPhone / iPad では、押したときに「ペースト」の確認が出るのでタップします。
  iPad でキーボードを付けているときは、窓が開いた状態で ⌘V でも貼り付けられます

写った人の姿勢を読み取って、「当てる」で人形に当てます。
Pinterest のアカウントとはつながず、コピーした画像だけを端末の中で読み取ります（画像はどこにも送りません）。
初回だけ検出モデルの取得に通信が必要です（以後はキャッシュされます）。
全身が大きく写っている写真ほど正確です。肩か腰が写っていないと組み立てられません。

### 写真と違いが出やすいところと、その手当て

写真は平面なので、奥行き（腕が前に出ているか後ろか）はどうしても推定になります。
また人形と写真の人では腕の長さや肩幅が少し違うので、関節の向きだけ写すと、
写真では頭に触れている手が人形では頭から離れる、といったずれが出ます。そこで「当てる」では次の順に合わせます。

1. **関節の向きを写す** … 体幹・腕・脚の向き（前の版と同じ）
2. **触れている所を合わせる** … 写真で手首が頭・反対の肩・肘・腰・膝・もう一方の手の近くにあれば
   「触れている」とみなし、人形の手がそこへ届くように肩と肘の角度を少しずつ直します
   （手を頭にのせる・腰に手・腕組み・合掌など）。直した所は知らせに「右手→頭」のように出ます
3. **手の向きを合わせる** … 写真の手首・人差し指・小指の位置から、手のひらの向きを合わせます
4. **手の形** … 手の写っている所を切り出して指の関節を読み取り、指の曲げ・開きを人形の手に当てます。
   手が小さく写っている・ぼけている・物を握っている・指どうしが重なっている写真では読み取れないか、
   形が少し違います（読み取れなかった手はそのままです）。表情は反映されません

当てたあとは**写真の向き（正面）から見て、写真を半透明で重ねます**。
下の帯の「重ねる」で重ね表示の入/切、「写真の向きから見る」で正面に戻せます。
違っている所は、関節を直接つまんで動かすと合わせやすいです。

## 頭身について

どの値でも**背丈は変わらず**、頭と体の比だけが変わります。

- 頭の高さ（あご先〜頭頂）は**背丈 ÷ 頭身**。モデル本来の頭の高さは**背丈 ÷ 7.5** を目安に決め
  （おとなの実測値は ANSUR 1988 で 男 7.56 / 女 7.46）、スキンの重みから測った箱が**その値と 25% 以内で一致したときだけ**
  そちらを採用します
- 頭身は**見た目のあご先（顔の前側のいちばん下）から頭頂まで**で数えます。頭の部品は首の受け口（あごの裏）が
  あご先より下へ伸びているので、箱の底から数えると頭が大きく数えられ、頭身が設定より高く見えます
  （サンプル素体で 1.5cm、2 頭身のつもりが 2.14 頭身になっていました）。
  サンプル素体（X Bot）の頭は、あご先〜頭頂 0.237m＝7.2 頭身です
- 面で捉えた頭部を出しているときは、その殻の高さで頭身を数えます（殻は元の頭より少し大きいため）
- 実測（背丈 ÷ あご先〜頭頂）は、2 頭身で 2.03、3 頭身で 3.02、5 頭身で 5.01、面で捉えた頭部では 2.00・3.00・4.99 です
- 体は、骨ごとに**長さ（骨の向き）と太さ（それと直角な向き）を別々に**伸び縮みさせます。
  前は骨を丸ごと縮めていたので、脚を短くすると脚も細くなり、低頭身でひょろ長い手足になっていました。
  いまは脚を短くしても太さは保ち、むしろ太くするので、ずんぐりしたデフォルメになります
- three.js の骨の倍率は子の骨にそのまま伝わり、向きの違う子では形がゆがむので、
  子の骨には親の伸び縮みを打ち消して渡します（Maya の Segment Scale Compensate と同じ考え方）。
  ひざやひじを曲げても、すねや前腕がつぶれたりねじれたりしません
- 頭は頭のボーンを中心に大きくなるので、あご先が大きく下がります。首の骨の長さは
  「あご先〜首の付け根」が表の長さになるように決め、あごが胸に沈まないようにしています
- 長さの合計がわずかに背丈と合わないぶんは、まず脚と胴の長さで取り返し、残りを体ぜんたいの倍率で合わせます
- **スライダーに触っていないあいだは、読み込んだモデルをそのまま出します**（倍率はすべて 1.0）
- 骨格を重ねていても、骨は肉と一緒に伸び縮みします

## 面で捉えた頭部

設定 →「見え方」→「**面で捉えた頭部**」で、眉の張り出し・眼窩のくぼみ・
頬骨の突出・鼻・エラ・あごを、平らな面の集まりとして表した頭に差し替えます。
面の変わり目には線が入るので、影の付き方を考えるときの手掛かりになります。

形は、参考にした低ポリ頭部の正面・真横・真上の画像からシルエットを実測して決めています。
横に14段の輪を積み、各段の幅は正面から、前後は真横から、断面のかたちは真上から取りました。
頭蓋の輪郭は実測と 2mm 以内で一致します。稜線は四角形の辺をそのまま線にしているので、
面の割り方が素直に出ます。

素体（人のモデル）を表示しているときだけ使えます。骨格・筋肉モデルの表示中は出ません。

### 解剖学に合わせた大きさと位置

おとなの頭の実測比率（米陸軍の人体計測 ANSUR 1988 の 50 パーセンタイル）に合わせてあります。

| 寸法 | 実測比 | この形 |
|---|---|---|
| 身長 ÷ 頭の高さ | 7.56（男）/ 7.46（女） | **7.5** |
| 頭の幅 ÷ 頭の高さ | 0.655 / 0.661 | **0.66** |
| 頭の奥行（眉間〜後頭部）÷ 頭の高さ | 0.849 / 0.858 | **0.84** |
| 鼻先〜後頭部 ÷ 頭の高さ | 約 0.93 | **0.94** |
| 目線（頭頂から） | 0.515 | **0.53** |
| 耳の穴（頭頂から） | 0.565 | **0.58** |

この形は実測比より 6% ほど横に広かったので、幅と奥行をまとめて 0.94 倍しています。

**縦の合わせ方**は、頭のボーンではなく**背丈**を基準にします。

- 頭の高さ＝**背丈 ÷ 7.5**
- 頭頂は「頭のボーン → 頭頂」（bbox と骨から分かる・信頼できる）のところ
- あご先は頭頂からその高さだけ下

頭のボーンを基準にしないのは、**リグによって頭のボーンの位置がばらばら**だからです。
頭を回す関節（環椎後頭関節）は解剖学的には頭頂から 0.65 頭分のところにあり、
そこにボーンがあるなら 頭の高さ ÷（ボーン→頭頂）= **1.54** になります。
一方 Mixamo のように頭のボーンがもっと下（あごの近く）にあるリグもあり、
そこでは同じ比が **1.1〜1.2** にしかなりません。
決め打ちにすると素体ごとに 3〜4 割ずれるので、ボーンでは上下に挟むだけ
（1.05〜1.75 倍）にして、寸法そのものは背丈から出しています。

首が隠れないことも確かめてあります。解剖学的には、

- あご先と首の骨の出っぱり（第七頸椎）は**ほぼ同じ高さ**（頭頂から 1.00 と 1.02 頭分）
- 首の付け根（胸骨の上のくぼみ）は頭頂から 1.37 頭分

なので、あご先が首のボーンより下へ行かないように頭の高さを抑えています。
殻のいちばん下はあご先より少し下＝あごの底なので、ちょうど首の始まりに乗ります。

### 元の頭は消す

面で捉えた頭部を出すときは、**元の頭を 0.02 倍まで縮めて見えなくします**。
殻の内側へ押し込もうとすると、眼窩の窪みから元の顔がのぞいたり、収めるために
殻を太らせることになります。消してしまえばその計算自体が要りません。

### 確かめ方

切り替えたときに

```
頭の高さ 0.227m（7.5頭身） ／ 頭頂 0.190 あご -0.037 首 -0.095 ／ 身長から算出
```

と画面に出ます（数字は頭のボーンからの高さ）。
「あご」が「首」より大きければ首は隠れていません。

## 骨格表示

設定 →「見え方」→「骨格を重ねる」、または表示するモデルを「骨格」にすると出ます
（初めて出すときに組み立てるので、1〜2 秒かかります）。

頭蓋骨（眼窩・鼻・頬骨・上顎・歯・下顎）、頸椎 7・胸椎 12・腰椎 5（椎体・椎間板・棘突起・横突起）、
仙骨・尾骨、肋骨 12 対と肋軟骨・胸骨、鎖骨・肩甲骨、上腕骨・橈骨・尺骨、手根骨・中手骨・指骨、
寛骨（腸骨・坐骨・恥骨・寛骨臼・恥骨結合）、大腿骨・膝蓋骨・半月板、脛骨・腓骨、
距骨・踵骨・足根骨・中足骨・趾骨 を組み立てます。

位置は**リグの関節**と、**素体を実際に測った体幹の断面**から決めます。

- 背骨 … 背中の面から一定の深さ（頸椎 4cm・胸椎 5.2cm・腰椎 6.2cm）。腰椎：胸椎＝17.5：28 の長さ
- 環椎 … 頭の中で頭頂から 0.65 頭分、前後の 58% の所
- 胸骨上切痕 … 第2・第3胸椎の高さ。肋骨は胸骨・肋軟骨・肋骨弓の付き方まで解剖図どおり
- 骨盤 … 左右の股関節の間隔から上前腸骨棘・腸骨稜・恥骨結合・坐骨結節を出す（Bell の式）
- 大腿骨 … 頸体角 125°・前捻 12°。骨幹は大転子から膝の真上へ斜めに下りる
- 前腕 … 手のひらを腿へ向けた（中間位）とき、橈骨は親指側、尺骨は小指側
- 足 … 足首・つま先の関節・かかとの後ろ・足の裏 から距骨・踵骨・中足骨を置く

できた骨は頂点ごとに**素体の内側か**を調べ、はみ出していれば体（手足）の中心へ寄せて縮めます。
頭蓋骨はばらばらにならないよう、まとまりのまま縮めて収めます。
全 76 ポーズを 24 方向から描いて確かめ、骨が見えるのは**球体関節のすき間や継ぎ目から数画素**だけです。

骨格は基準姿勢で組み立ててボーンの子にしてあるので、ポーズ・頭身・体型を変えても一緒に動きます。
面で捉えた頭部のときに元の頭を縮めても、頭蓋骨は元の大きさのまま残ります。

**骨には一つ一つ名前が付いています**（約 260 個。左右・番号ごと）。
手根骨は 8 個（舟状骨・月状骨・三角骨・豆状骨・大菱形骨・小菱形骨・有頭骨・有鉤骨）を形と大きさを変えて置き、
足根骨（距骨・踵骨・舟状骨・立方骨・内側／中間／外側楔状骨）、中足骨 1〜5、趾骨（母趾は 2 節）、
椎骨は第1頸椎（環椎）〜第5腰椎、肋骨・肋軟骨は第1〜第12 と、番号まで分けてあります。

前へ深く曲げたときに首の付け根（第7頸椎〜第2胸椎・第1肋骨）や坐骨が皮膚から出やすいので、そこは少し深めに収めます。

組み立てた骨格は体型ごとに取っておき、体型を切り替えたときは使い回します（2 回目からはすぐ切り替わります）。

## 筋肉表示（モデルが無くても出ます）

表示するモデルを「**筋肉**」にすると、筋肉モデルを読み込んでいなくても、
モデルのボーンと素体の形から**名前の付いた表層の筋肉**を組み立てて出します（初回は数秒かかります）。

- 頭・首 … 側頭筋・咬筋・前頭筋・眼輪筋・口輪筋・大頬骨筋・胸鎖乳突筋・僧帽筋
- 胴 … 大胸筋・前鋸筋・腹直筋（腱画つき）・外腹斜筋・広背筋・脊柱起立筋・棘下筋・大円筋
- 腕 … 三角筋（前・中・後）・上腕二頭筋・上腕筋・上腕三頭筋・腕橈骨筋・前腕の屈筋群／伸筋群・母指球・小指球
- 脚 … 大殿筋・中殿筋・大腿筋膜張筋・腸脛靭帯（白い帯）・縫工筋・大腿直筋・外側広筋・内側広筋・内転筋群・大腿二頭筋・
  半腱様筋／半膜様筋・腓腹筋・ヒラメ筋・アキレス腱・前脛骨筋・長腓骨筋

見た目は美術解剖の図に合わせて、筋肉は赤橙に**筋線維の細い筋**を入れ、腱・腱膜（腹直筋の腱画、両端の腱など）は白っぽいクリーム色にしています。
筋肉と筋肉のあいだは腱膜・筋膜の白で見えるので、白線（お腹の正中）・腰の胸腰筋膜・腿の外側の腸脛靭帯・膝・手首・足首が白く出ます。
女性のときは、乳房を乳腺・脂肪の黄色で大胸筋の上に重ねます。

設定 →「見え方」→「**筋肉を種類ごとに色分け**」をオンにすると、筋肉ごとに違う色になります（左右は同じ色、腱は白のまま）。
どの筋肉がどこからどこへ付いているかを見分けるのに使えます。筋肉を出していないときにオンにすると、筋肉の表示に切り替えます。

左右合わせて約 80 個。作り方は、起始（付け根）と停止（付く先）の位置を体の「枠」の中で決め、
そのあいだを筋線維の束としてつなぎ、素体の表面のすぐ内側に置きます。
素体（球体関節の人形）は胸の殻とお腹の玉のあいだが関節のくびれで、人の胴よりずっと細いので、
筋肉をそのまま沿わせるとコルセットで絞ったように見えます。胸の下〜骨盤のあいだは、
胸の幅と腰の幅をつないだ線から少しだけくびれる幅まで、筋肉と下の白い層を広げます
（くびれの強さは 男性 5%・中性 8%・女性 14%）。
腿の筋肉は、腿の骨の線から 17cm 先までを外から測ります（女性の腰の張り出しまで届くように。
以前は 11.5cm で止めていたため、女性の腰の横〜腿の付け根の外側に筋肉が届かず、白くふくらんで見えていました）。
腰の横は、中殿筋（腸骨稜の前 2/3 → 大転子）と大腿筋膜張筋（上前腸骨棘 → 腸脛靭帯）で覆い、
腿の外側は外側広筋の上を腸脛靭帯の白い帯が膝の外側（脛骨のガーディー結節）まで下ります。
**筋肉は皮下脂肪の分だけ皮膚の内側に置きます**（解剖学では、筋肉の上に脂肪の層があるため）。
厚みの目安（cm）は、男性：胸 0.4・おなか 1.0・お尻と腰 1.0・腿 0.6・すね 0.35・二の腕 0.4、
女性：胸 0.6・おなか 1.6・お尻と腰 3.0・腿 1.8・すね 0.7・二の腕 0.9。腿は付け根ほど厚く、膝の上は薄くします。
そのため筋肉の表示では、とくに女性の腰〜腿が素体より一回り細く見えます（素体の丸みの多くは脂肪のため）。
筋肉の腹は皮膚より 1.5mm までしか外へ出しません（ふくらみを足しすぎると腿などが太って見えたため）。
表面までを測るときは、その筋肉の体の部分の皮膚だけを数えます。腿の横に下ろした手の表面などで止まらないようにするためです
（以前はそのせいで、腿の筋肉が手の位置まで太って見えることがありました）。
腹は、腹直筋（白線の両わき、腱画 3 本）と外腹斜筋（前と下は白い腱膜）で覆い、腰は胸腰筋膜（白いひし形）で覆います。
筋肉の表示では、胴の骨（背骨・肋骨・骨盤・肩甲骨）は筋肉の下に隠れるので出しません。
表面までの距離は**外から内へ**測ります（内から外へ測ると、胴の中にある関節の玉などの表面で止まり、
大胸筋などが胸の殻よりずっと奥に置かれて見えなくなっていたため）。筋肉の腹はふくらみ、端の腱は細く沈みます。
筋肉と筋肉のあいだは、素体を少し内側へ縮めた暗い層が「溝」として見えます。
スキンの重みは、その点の真上の皮膚の重みを写すので、ポーズを付けても皮膚と一緒に動きます。
顔・頭の筋肉（前頭筋・眼輪筋・口輪筋・側頭筋・咬筋・大頬骨筋）と胸鎖乳突筋の頭の側は、素体の頭の表面ではなく
**頭蓋骨の表面までの距離を測って骨の上に**置きます（素体の頭はつるっとした卵形で骨より 1〜2cm 大きいので、
表面に置くと頭蓋骨から浮いて見えるため）。そのため筋肉を出すときは先に骨格を組み立てます。
形は美術解剖学の図を単純化したものです（深層の筋・手足の細かい筋は入れていません）。

## 骨・筋肉の名前を調べる

設定 →「見え方」→「**骨・筋肉の名前を調べる**」をオンにすると、骨や筋肉を**タップしたところの名前**が
パネルの上のカードに出て、その部品が光ります。カードには日本語名・ラテン語名・説明、
筋肉なら**起始・停止・はたらき**が出ます。

素体だけを表示しているときは、自動で骨格を重ね、素体を透かします（オフにすると元に戻ります）。
「一覧」から、骨／筋肉・部位（頭・首・胴・骨盤・肩と腕・手・脚・足）・名前で探して選ぶこともできます。

## 補助線

設定 →「カメラ」→「補助線」で、絵を描くときの当たりを画面に重ねます。

- **頭身の線** … まっすぐ立ったときの頭頂から、頭ひとつぶんごとの水平線と番号（いまの頭身に合わせる）
- **正中線** … 恥骨〜腰〜胸〜首〜頭をつなぐ体の中心の線（ポーズに付いてくる）
- **肩と腰の傾き** … 左右の肩・左右の股関節を結んだ線

画像に書き出すときは、補助線も一緒に入ります。

## カメラの向き

設定 →「カメラ」で、正面・斜め前（左／右）・左横・右横・後ろ・上から・下から（あおり）・真上 に一度で回せます。
左右は人形から見た左右です。手だけ・足だけのときは、手（足）の向きを基準に回します。

## ポーズの保存と画像の書き出し

ポーズ →「保存」→「いまのポーズを保存」で、名前を付けて端末の中に残します（関節の角度と手の形）。
タップで呼び戻し、「削除」で消せます。

「画面を画像に」で、いまの画面を PNG にします。iPhone / iPad では共有シートが開くので、
「画像を保存」で写真に入れられます。選択の印・回転の輪・光の矢印は外して書き出します。

「**背景を透過して画像に**」（v44）は、背景の色と床の線を抜いた PNG です。お絵描きアプリに読み込んで、
下絵や参考として重ねられます。

- 書き出すと、**市松模様の上に結果を出す確かめの窓**が開きます（v45）。市松模様が見えている所が透明です。
  「保存・共有」で共有シート（写真に保存・ファイルに保存など）、「コピー」でお絵描きアプリに直接貼り付けられます
- 写真アプリでは、透明な所が白か黒に見えます（透明でも、表示のための色が付く）。お絵描きアプリに読み込むと抜けています
- 作り方（v45 で変更）: 背景を**黒にしたものと白にしたものを 1 回ずつ描き、2 枚の違いから透け具合を出します**。
  人形は 2 枚で同じ色、背景は黒と白で違い、半透明の影はその間になります（透け具合 = 1 −（白 − 黒））。
  端末の WebGL が透明な画面を作れるかどうかに頼らないので、iPhone / iPad でも同じように抜けます
  （v44 は WebGL の画面の透明に頼っていたため、端末によっては抜けませんでした）

- **透過のとき床の影も入れる** … 床に落ちる影だけ半透明で残します（はじめは切）
- **透過のとき人形のまわりで切り抜く** … 人形のまわりに少し余白を付けて切り抜きます（はじめは入）
- 補助線を出しているときは、補助線も入ります。素体を透明にしているときは、その透け具合のまま書き出します

## 読み込んだモデルにポーズを取らせる

まずボーン名で関節を探します。名前で12個そろわないときは、**ボーンのつながりと位置**から
割り出します（頭頂へ至る道筋を背骨、そこから左右に出る枝を腕、下へ伸びる枝を脚とみなし、
「続けて2本いちばん長い区間」を上腕と前腕・腿とすねに当てる）。
解剖学の名前が付いた骨格モデルや、鎖骨のないリグでも当たります。

どちらで割り出したか、どの関節がどのボーンに当たったかは、
設定 →「読み込んだモデルの中身」で確認できます。

## 設定の並び

ポーズタブと設定タブは、中身を**横にスライドして切り替え**ます。
上の見出しをタップしても移動できます。縦に積まないので、パネルを低くしたままでも操作できます。

設定は4枚（**見え方**／**体とモデル**／**ライト**／**カメラ**）。見出しは横に並べて全部が一度に見えます。

- 見え方 … 見る範囲・表示するモデル・質感・透明・面の線・面で捉えた頭部・骨格を重ねる・骨と筋肉の名前
- 体とモデル … 体型・頭身・読み込んだモデル・すべての設定を初期値に戻す
- ライト … ライトの組み合わせ・強さ・向き・補助光・環境光・影・露出・光の玉
- カメラ … カメラの向き・レンズ・補助線・床グリッド・全体を表示

見出しをタップしてなめらかに移るあいだ、途中のページの見出しが光らないようにしました
（以前は動いている途中のページも一瞬印が付いて、二つ光っているように見えることがありました）。

ポーズの一覧は左右にスライドするほか、下の **‹ ›** でもページを送れます。
**パネルの高さに合わせて1ページぶんの数が決まります**（半分の段で 9 個前後、広い段で最大 24 個）。
ページが12を超えるときは、点ではなく `3 / 22` と数で位置を出します。

## 画面の回転

キャンバスの大きさは `ResizeObserver` で見張り、`orientationchange` の後は 100 / 300 / 700ms で
測り直します。iOS は回転した直後だとまだ古い大きさを返すことがあり、そのまま縦横比を決めると
素体が縦や横に伸びて見えるためです。
