# Posit

絵を描くための 3D デッサン人形。ブラウザだけで動き、ホーム画面に追加するとアプリのように開きます。

## 置き方（GitHub Pages）

1. この**フォルダの中身**をリポジトリの**直下**に置く
   （`index.html` がリポジトリのトップに来るようにする。フォルダごと入れない）
2. Settings → Pages → Source を `Deploy from a branch` → `main` / `(root)` → Save
3. 1〜2 分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` が開く
4. **Safari** で開き、共有 → 「ホーム画面に追加」

リポジトリは Public にしてください。Private のままだと Pages は有料プランが必要です。

## 更新のしかた

変更したファイルを push するだけです。ページを開き直すと新しい版に自動で入れ替わります
（Service Worker が新しくなると、一度だけ自動で読み直します）。

うまく切り替わらないときは、パネルの「**困ったとき**」→「**キャッシュを消して再読込**」。
同じ場所に今動いているバージョンが出ます。

## 画面

下のタブで切り替えます。

- **ポーズ** — 4つに切り替わります
  - **全身**: 9カテゴリ76ポーズ。「ランダム」と「写真から」もここ
  - **手**: グー・パー・OK など16種を、両手／左手／右手に当てる
  - **顔**: 見上げる・振り向く・口を開けるなど14種
  - **履歴**: 直近30件から呼び戻す
- **関節** — 選んだ関節を3軸で動かします。人形を直接タップしても選べます
- **設定** — 見る範囲、頭身、体型、素体の見え方（面の線・面で捉えた頭部）、表示するモデル、質感、ライトと影、カメラ、モデルの読み込み（おすすめモデルへのリンク付き）、困ったとき
- **クロッキー** — 時間・枚数・カテゴリを決めて全画面で回します

タブバーは常に画面下に出ています。パネルをたたむと人形だけになります。

上部の3つのボタンは、左から「1つ戻す」「左右反転」「全身リセット」です。
左端の山形ボタン（またはパネル上部の横棒）でパネルをたたむと、人形を大きく見られます。

## モデルの読み込み方

**Sketchfab** からダウンロードした **zip をそのまま選べます**。展開の必要はありません。

1. Sketchfab でモデルのページを開き、Download 3D Model（無料登録が必要）
2. 形式は **glTF** を選ぶ（USDZ ではなく）
3. ダウンロードした zip を、設定 → モデル → 読込 で選ぶ

`.gltf` 単体では読み込めません。中身が `scene.bin` という別ファイルに入っているためです。
すでに展開してしまった場合は、**scene.gltf と scene.bin をまとめて選択**してください。

GLB の1ファイル、Mixamo から書き出した FBX は、そのまま1つ選ぶだけです。

## 見る範囲と体型

設定タブで切り替えます。

- **見る範囲** — 全身 / 上半身 / 顔 / **手だけ** / **足だけ**。手と足は手首・足首の少し上で切って、
  その部分だけを大きく見られます。左右はチップで切り替えます
- **体型** — 中性 / 男性 / 女性。骨の配置で肩幅と腰幅を変えます
  （メッシュは共通なので、本格的に分けたいなら男女別モデルを読み込んでください）
- **面の線を出す** — 面の割れ方が見えるので、陰影を取るときの参考になります

## 頭身

設定 → 頭身 のスライダで **2〜9 頭身**に変えられます。
頭が大きくなるだけでなく、**胴と手足も短くなる**ので、低頭身にするとデフォルメが効きます。
背丈そのものは変わらないので、画面上の大きさは保たれます。

## クロッキーの見え方

クロッキータブで、**出題中だけ**の見え方を決められます。

- 表示するモデル（素体 / 筋肉 / 骨格 / 重ねて）
- 見る範囲（全身 / 上半身 / 顔 / 手だけ / 足だけ）
- 面の線

終わると元の見え方に戻ります。手だけを 30 秒で回す、といった練習ができます。

## 写真からポーズを読み取る

ポーズタブの「写真から」で写真を選ぶと、写った人の姿勢を読み取って人形に当てます。
初回だけ検出モデルの取得に通信が必要です（以後はキャッシュされます）。
全身が大きく写っている写真ほど正確です。肩か腰が写っていないと組み立てられません。

読み取れるのは体幹・腕・脚の向きまでで、手の形と表情は反映されません。

## 頭身について

スライダーは 2〜12 頭身。どの値でも**背丈は変わらず**、頭と体の比だけが変わります。

- 体は腰のボーンを丸ごと縮めるので、骨の間隔だけでなく肉付きも一緒に縮みます
  （かかとから脚が突き抜けることがありません）
- 低頭身ほど手足を追加で詰めます（2頭身で脚 3割・腕 3.8割）。
  詰めたぶんは胴が引き受けるので背丈は変わらず、胴が相対的に太くなってデフォルメが効きます
- 頭の高さは**スキンの重みから実測**します（頭のボーンに引っ張られる頂点の箱）。
  ボーンの位置から当てるとリグによって外れるためです。表示される頭身と実際の見た目が一致します
- 実測が妥当でないとき（頭身が 3〜12 の外、縦横の比が頭らしくない、頂点が少なすぎる）は採用せず、
  骨からの推定に戻します。測り損ねた値で体型が崩れないようにするためです
- **スライダーに触っていないあいだは、読み込んだモデルをそのまま出します**（倍率はすべて 1.0）
- 胴の伸びには上限（1.8倍）があり、超えそうなときは先に脚の詰め幅のほうを減らします

## 面で捉えた頭部

設定 →「素体の見え方」→「**面で捉えた頭部**」で、眉の張り出し・眼窩のくぼみ・
頬骨の突出・鼻・エラ・あごを、平らな面の集まりとして表した頭に差し替えます。
面の変わり目には線が入るので、影の付き方を考えるときの手掛かりになります。

形は、参考にした低ポリ頭部の正面・真横・真上の画像からシルエットを実測して決めています。
横に14段の輪を積み、各段の幅は正面から、前後は真横から、断面のかたちは真上から取りました。
頭蓋の輪郭は実測と 2mm 以内で一致します。
大きさはモデルの頭の実寸（スキンの重みから測った箱）に合わせます。高さと幅の両方で収まる倍率を選ぶので、
元の頭より大きくなることはありません。稜線は四角形の辺をそのまま線にしているので、面の割り方が素直に出ます。

素体（人のモデル）を表示しているときだけ使えます。骨格・筋肉モデルの表示中は出ません。

頭の大きさは二通りの測り方で拾います。

1. **スキンのモデル** … 頭のボーン（とその先）に主に引っ張られる頂点
2. **パーツ分けのモデル** … 頭のボーンにぶら下がった、スキンでないメッシュ

球体関節のデッサン人形は 2 のことが多く、1 だけだと何も拾えません。
あごの高さは「箱の底」と「首のボーン」の高いほうを採ります。これで、
頭のメッシュが首にかかっているモデルでも、首が別パーツのモデルでも、首を覆いません。
前後方向の中心もそろえるので、あごが前へ出ることもありません。

**縦**は「あご〜頭頂」をぴったり合わせます。**横と奥行**は、元の頭が殻の内側へ本当に入るところまで
広げます。その判定は二分法で解きます（殻の頂点がひとつでも元の頭の中に入っていたら、はみ出している）。
眼窩は殻の内側へ深くへこんでいるので、ここを決め打ちにすると元の頭が眼窩を突き抜けて
殻がまるごと隠れ、「顔が小さくなるだけ」に見えます。
この解き方だと元の頭の縮小は 0.94 前後で済み、首もほとんど引っ張られません。

## 読み込んだモデルにポーズを取らせる

まずボーン名で関節を探します。名前で12個そろわないときは、**ボーンのつながりと位置**から
割り出します（頭頂へ至る道筋を背骨、そこから左右に出る枝を腕、下へ伸びる枝を脚とみなし、
「続けて2本いちばん長い区間」を上腕と前腕・腿とすねに当てる）。
解剖学の名前が付いた骨格モデルや、鎖骨のないリグでも当たります。

どちらで割り出したか、どの関節がどのボーンに当たったかは、
設定 →「読み込んだモデルの中身」で確認できます。

## 画面の回転

キャンバスの大きさは `ResizeObserver` で見張り、`orientationchange` の後は 100 / 300 / 700ms で
測り直します。iOS は回転した直後だとまだ古い大きさを返すことがあり、そのまま縦横比を決めると
素体が縦や横に伸びて見えるためです。
